> [!WARNING]

> ### Реакция антивируса
>
> Антивирус может отреагировать на WinDivert.  
> Этот инструмент перехватывает и фильтрует трафик и нужен zapret для работы.
> WinDivert может применяться как безопасными, так и вредоносными программами, однако сам вирусом не является.
>
> **Фрагмент [`readme.md`](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B) проекта [bol-van/zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle)*
>
> Некоторые антивирусы считают файлы WinDivert потенциально опасными или относят их к хакерским инструментам. В результате файл удаляется и отправляется в карантин. Название обнаружения обычно содержит `WinDivert` или `Not-a-virus:RiskTool.Multi.WinDivert`
>
> Добавьте каталог с zapret в исключения антивируса либо отключите обнаружение PUA (потенциально нежелательных приложений). Например, Kaspersky предлагает параметр "Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда". Если вы уверенно понимаете настройки исключений, лучше настроить исключение; в противном случае рекомендуется отключить обнаружение PUA.

## ⚙️Использование

1. Настройте безопасный DNS (Secure DNS)
    * В Chrome включите "Использовать безопасный DNS" и выберите поставщика, отличного от "Поставщик по умолчанию"
    * В Firefox откройте "DNS через HTTPS", установите режим "Персональный", нажмите "Выбрать провайдера/поставщика" и вручную укажите URL. Например: `https://dns.google/dns-query` (провайдер Cloudflare может быть заблокирован)
    * Windows 11 позволяет включить Secure DNS в настройках самой системы — [инструкция](https://remontka.pro/dns-over-https-windows-11/). Для Windows 11 этот вариант рекомендуется
    * Пользователям роутеров Keenetic нужно включить в настройках параметр "Транзит запросов". При его отключении Secure DNS на компьютере может работать некорректно

2. Загрузите zip/rar-архив с [последнего релиза](https://github.com/crushanbugap/zapret-discord-youtube/releases/latest)

3. Откройте свойства архива и отметьте "Разблокировать". При использовании 7-Zip или PeaZip этот пункт можно не выполнять

4. Распакуйте архив в каталог без кириллицы и специальных символов в пути

5. Запустите необходимый файл
    * Чтобы подобрать рабочую стратегию, откройте **`service.bat`** -> `Run Tests` -> `Standard tests` -> `All configs`
    * Для автоматического запуска перейдите в **`service.bat`** -> `Install Service` -> *выберите подходящую стратегию*

## ℹ️Краткие описания файлов

- [**`general.bat ...`**](./general.bat) — ручной запуск стратегии

  Такой запуск удобен для проверки стратегий. Результат зависит от множества условий, поэтому **перебирайте разные варианты (ALT, FAKE и другие), пока не найдёте подходящий**

- [**`service.bat`**](./service.bat) — автозапуск и дополнительные действия:
  - <ins>**`Install Service`** — добавить выбранную стратегию в автозапуск служб (services.msc)</ins>
  - **`Remove Services`** — удалить стратегию и WinDivert из служб
  - **`Check Status`** — показать состояние обхода и служб, включая стратегию автозапуска и WinDivert
  - **`Game Filter`** — изменить режим обхода для игр и других сервисов, использующих UDP и TCP-порты выше 1023.  
  **После изменения режима стратегию необходимо перезапустить.**  
  Состояние функции отображается в скобках: включена она или выключена.
  - **`IPSet Filter`** — переключить обход ресурсов из `ipset-all.txt`.  
  Этот параметр полезен при проверке ресурса, который без zapret работает, а с ним — нет.  
  В скобках показывается состояние:
    - `none` — ни один IP не проверяется
    - `loaded` — IP проверяется по списку
    - `any` — под фильтр попадает любой IP  
  - **`Auto-Update Check`** — включить или выключить автоматический поиск обновлений
  - **`Replace active fakes`** — заменить текущий фейк другим файлом из каталога `bin`
  - **`Update IPSet List`** — получить актуальный `ipset-all.txt` из репозитория
  - **`Update Hosts File`** — обновить hosts <ins>**для восстановления веб-версии Telegram и подключения Discord к голосовому чату**</ins>
  - **`Check for Updates`** — вручную проверить наличие обновлений
  - **`Run Diagnostics`** — проверить распространённые причины неисправности zapret.  
  В завершение можно удалить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; иногда это возвращает работоспособность приложения
  - **`Run Tests`** — запустить проверку стратегий:
    - `Standard tests` — проверить сайты из `utils/targets.txt`
    - `DPI checkers` — проверить DPI у разных провайдеров, включая Cloudflare и Amazon


## ☑️Распространенные вопросы и проблемы

### После запуска `general*` ничего не появляется

При запуске стратегии отдельным bat-файлом, а не через service, должен запуститься winws.exe. Его можно увидеть на панели задач.  
Если процесс не появился, обратитесь к [#522](https://github.com/crushanbugap/zapret-discord-youtube/issues/522)

### Ни одна стратегия не работает
- Откройте командную строку с правами администратора
- Выполните команды по очереди:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`

- Перезагрузите компьютер

### Не открывается Telegram в браузере
Запустите **`service.bat`** и выберите **`Update hosts file`**. Если файл hosts устарел, программа предложит обновить его вручную:  
  - Скопируйте всё содержимое открывшегося блокнота
  - Откройте от имени администратора файл `hosts` в созданной папке с помощью текстового редактора
  - Вставьте скопированный текст в конец `hosts` или замените им ранее добавленный аналогичный блок
  - Сохраните файл и проверьте подключение ещё раз. Если результата нет, убедитесь, что изменения действительно сохранились.

#### Работа не гарантируется. Если этот способ не помог, используйте [версию Desktop](https://github.com/telegramdesktop/tdesktop/releases) с [локальным прокси](https://github.com/crushanbugap/tg-ws-proxy) или любым публичным прокси.

### Обход не запускается или снова перестал работать

> [!IMPORTANT]
> **Стратегии со временем могут терять работоспособность.**
> Стратегия может некоторое время справляться с блокировкой, а затем перестать работать после обнаружения.
> В репозитории собрано много вариантов обхода. Если готовые варианты не подходят, создайте новую стратегию на основе одной из них, изменив параметры.
> Описание параметров находится [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- Убедитесь, что `service.bat` -> `Run Diagnostics` не показывает ошибок

- Проверьте наличие адреса ресурса в доменных или IP-списках

- Попробуйте другие стратегии, включая **`ALT`** и **`FAKE`**

- Выполните полную переустановку по инструкции ниже

- Дополнительная информация есть в [#765](https://github.com/crushanbugap/zapret-discord-youtube/issues/765)

### Как полностью обновить или переустановить проект?
- Сохраните добавленные вами ресурсы и другие данные
- Перезапустите устройство
- Выполните `service.bat` -> `Remove Services`
- Запустите `service.bat` -> `Run Diagnostics`; исправьте найденные ошибки и в конце ответьте Y
- Удалите каталог zapret
- Скачайте свежую версию со [страницы релизов](https://github.com/crushanbugap/zapret-discord-youtube) (`zapret-discord-youtube-...`)
- Нажмите правой кнопкой по архиву и откройте свойства. Если внизу есть пункт разблокировки, отметьте его, нажмите «Применить», затем «ОК»
- Распакуйте архив в новый каталог в корне диска; путь не должен содержать пробелы и специальные символы
- Запускайте разные скрипты `general` и проверяйте доступ к ресурсам. Если доступ не появился, закройте программу через значок замка на панели задач и выберите другую стратегию
- Найдя рабочий вариант, добавьте его в автозапуск через `service.bat` -> `Install Service` -> нужная стратегия

### Игра или приложение не работает при включённом zapret

- В `service.bat` проверьте, что `Game Filter` установлен в **`disabled`**, а `IPSet Filter` — в **`none`**. Иначе обход может повлиять на ресурсы, которые вы не планировали фильтровать.

### Античит сообщает о WinDivert

- Ознакомьтесь с инструкцией: https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### Windows 7 требует цифровую подпись драйвера WinDivert

- В каталоге [`bin`](./bin) замените `WinDivert.dll` и `WinDivert64.sys` одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7)

### После удаления через [**`service.bat`**](./service.bat) WinDivert всё ещё есть среди служб

1. В командной строке Windows (Win+R, `cmd`) найдите имя службы:

```cmd
driverquery | find "Divert"
```

2. Остановите службу и удалите её следующими командами:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не открывается <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте настройку [Secure DNS](#%EF%B8%8Fиспользование)
- Отключите блокировщик рекламы: известно, что YouTube начал с ними бороться.
- Если прежняя стратегия перестала помогать, проверьте все остальные.
- См. также [#251](https://github.com/crushanbugap/zapret-discord-youtube/discussions/251)

### Не подключается <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что включён [Secure DNS](#%EF%B8%8Fиспользование)
- Сначала желательно определить стратегию, на которой открывается YouTube, и запустить её
- В `service.bat` откройте `Run Diagnostics` и очистите кэш Discord
- Проверьте приложение Discord после очистки кэша
- Откройте Discord в браузере: https://discord.com/app. Если веб-версия работает, её можно использовать
- Если Discord не работает и в браузере, повторно проверьте все стратегии: YouTube и Discord могут работать на разных вариантах
- См. также [#252](https://github.com/crushanbugap/zapret-discord-youtube/discussions/252)

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Воспользуйтесь [tg-ws-proxy](https://github.com/crushanbugap/tg-ws-proxy)
- Либо подключите бесплатный MTProto-прокси из интернета

### Игры не работают

Игр много, поэтому проверить и исправить каждую из них невозможно.

Универсальный порядок действий:
- через `service.bat` обновите ipset и включите `Game Filter`
- если это не помогло, дополнительно включите `ipset any`

Учитывайте, что режим `ipset any` может нарушить открытие множества сайтов. Не оставляйте его включённым постоянно: выясните IP-адреса, используемые игрой, и внесите их в `ipset-all.txt`

Если проблема останется, создайте обсуждение в разделе [Discussions](https://github.com/crushanbugap/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

- Опишите её [здесь](https://github.com/crushanbugap/zapret-discord-youtube/issues)

## 🗒️Добавление адресов прочих ресурсов

Адреса для обхода добавляются в следующие файлы:
- **`list-general-user.txt`** — домены; поддомены учитываются автоматически
- **`list-exclude-user.txt`** — домены, которые нужно исключить (например, если IP сети есть в `ipset-all.txt`, но конкретный домен фильтровать не следует)
- **`ipset-all.txt`** — IP-адреса и подсети
- **`ipset-exclude-user.txt`** — IP-адреса и подсети-исключения
  - Файлы **`*-user.txt`** создаются автоматически при первом запуске `zapret` или `service.bat`
